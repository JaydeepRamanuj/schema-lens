## Brand & Style

This design system expresses the precision and low-latency power of an engineering instrument built at the boundary of relational database engines and autonomous AI agent workflows. The visual identity draws from developer-first, high-polish aesthetics popularized by Linear, Vercel, and Supabase: quiet restraint, immaculate alignment, zero ornamental fluff, and electric luminescence where interaction or telemetry demands it.

The aesthetic fuses **Minimalism** and **Glassmorphism** with an ambient **Cybernetic Tone**:
- **Canvas Atmosphere**: Pitch obsidian depths (`#05070f`, `#09090b`) replace generic corporate grays, acting as an absorbing void where live syntax, foreign-key link chains, and vector cosine telemetry illuminate without optical fatigue.
- **Lighting Mechanics**: Frosted glass panes (`rgba(13, 17, 28, 0.72)`) with subtle specular hairline borders (`rgba(255, 255, 255, 0.08)`) and deep radial background glows (`#06b6d4`, `#3b82f6`) provide tactile elevation without heavy opaque drop shadows.
- **Audience & Tone**: AI systems engineers, database architects, and autonomous coding agent practitioners (Claude Desktop, Cursor, Antigravity, Copilot). The interface communicates absolute speed, surgical predictability, and zero token waste.

## Colors

The palette is tuned specifically for deep nocturnal developer environments with high contrast and optical clarity.

### Primary Spectrum
- **Primary (`#06b6d4` / Neon Cyan)**: Central photonic anchor. Dictates focused states, active indicators, schema traversal vectors, and primary action fills.
- **Primary Hover (`#22d3ee`)**: Accelerated illumination state for interactive triggers and glowing border reflections.
- **Secondary (`#3b82f6` / Electric Blue)**: Partner gradient accent signaling foreign key links, network traversals, and multi-tier agent pipelines.
- **Tertiary (`#10b981` / Emerald Protocol)**: Verified engine states, live MCP connections, and active indexing cache indicators.
- **Neutral Canvas (`#05070f` / Deep Obsidian)**: The subterranean canvas. Supported by `#09090b` (base container surfaces) and `#0f1422` (cards and code displays).

### Telemetry Signals
For search matching and schema telemetry badges:
- **Lexical FTS**: `#4fc1ff` text on `#0d3d52` container.
- **Fuzzy Match**: `#569cd6` text on `#1a3a52` container.
- **Value Match**: `#ce9178` text on `#3d2f0d` container.
- **Semantic / Cosine**: `#4ec9b0` text on `#0d3d2a` container.
- **Warning / Cache Drift**: `#f59e0b` text on `rgba(245, 158, 11, 0.14)`.
- **Error / Constraint Break**: `#ef4444` text on `rgba(239, 68, 68, 0.14)`.

## Typography

The typographic hierarchy relies on a strict dual-font foundation: proportional geometric cuts for narrative structure and technical tabular monospace for code, metrics, and schema tokens.

- **Proportional Voice (Geist / Inter fallback)**: Negative tracking across hero displays and headlines tightens letterforms, projecting density and intentional craft. Standard body copy maintains open, legible leading (1.55x) for prolonged terminal readout without cognitive fatigue.
- **Monospace Voice (Geist Mono)**: Tabular alignment is enforced for all CLI commands, latency calculations (`2.14ms`), database field typings, and schema metadata. Numerical layouts use strict tabular spacing to eliminate layout thrashing during live agent queries.
- **Case System**: Use full uppercase with expanded tracking (`0.05em` to `0.06em`) exclusively on metadata eyebrow tags, engine telemetry badges, and column constraints (`PK`, `FK`, `INDEXED`).

## Layout & Spacing

The layout balances macro-scale hero breathing room with micro-scale technical data density:

- **Grid Architecture**: 12-column fluid grid system bounded by a maximum container width of `1280px` (`80rem`). Responsive adaptation collapses to a 2-column or asymmetric bento layout on tablet viewports (<1024px) and a single continuous stack on mobile (<768px).
- **Rhythm & Multiples**: All padding, component dimensions, and layouts resolve to an uncompromising 4px base increment (`space-xs: 4px`, `space-sm: 8px`, `space-md: 16px`, `space-lg: 24px`, `space-xl: 32px`).
- **Section Transitions**: Macro landing page sections employ deep vertical breathing intervals of `80px` to `120px` on desktop, framing floating code consoles and interactive schema visualizers.
- **Bento & Data Viewports**: Interior data cards utilize strict `24px` internal padding, preserving a clean boundary around code trees and preventing dense relational schema tables from colliding with perimeter borders.

## Elevation & Depth

Rather than relying on generic murky shadows, this design system creates depth through **photonic backlighting, glassmorphism, and specular surface borders**.

- **Ground Zero / Void (0dp)**: Subterranean `#05070f` backdrop overlaid with an ultra-faint radial dot grid (`radial-gradient(circle, rgba(255, 255, 255, 0.05) 1px, transparent 1px)` at 24px increments).
- **Photonic Ambient Layer (1dp)**: Positioned luminous wells behind high-value elements—such as a 600px radial glow of `rgba(6, 182, 212, 0.12)` positioned directly behind the CLI showcase terminal.
- **Frosted Container / Surface Card (2dp)**: `rgba(13, 17, 28, 0.72)` background paired with `backdrop-filter: blur(20px)`, framed by an ultra-thin 1px border (`rgba(255, 255, 255, 0.08)`) and a subtle top specular inner highlight (`box-shadow: inset 0 1px 0 0 rgba(255, 255, 255, 0.09)`).
- **Elevated Interactive Floating Window (3dp)**: Elevated card containers (`#0f1422`) with an ambient drop shadow (`0 24px 48px -12px rgba(0, 0, 0, 0.8)`) and dynamic cyan-to-blue hairline border transitions on focus or cursor hovering.
- **Overlays, Menus & Tooltips (4dp)**: Translucent obsidian overlay (`rgba(19, 25, 43, 0.95)`) backed by a 24px blur, a `rgba(255, 255, 255, 0.16)` perimeter outline, and deep directional shadow (`0 32px 64px -16px rgba(0, 0, 0, 0.9)`).

## Shapes

The design uses balanced, modern developer-tool curves (`roundedness: 2`):

- **Baseline Components (0.5rem / 8px)**: Standard buttons, text input fields, code chips, and interactive table rows use an 8px radius for a clean, precision-tooled contour.
- **Card & Bento Panels (1rem / 16px)**: Feature bento cards, terminal window shells, and schema visualizer containers take 16px rounding to soften high-density code presentations.
- **Badges & Engine Signals (Full Pill / 9999px)**: Status badges (e.g., `MCP Live`), protocol connectivity pills, and telemetry chips use full pill shapes to contrast against rectangular table rows and terminal windows.

## Components

### Buttons
- **Primary CTA**: Linear gradient fill from `#06b6d4` to `#3b82f6` with contrast obsidian text (`#05070f`, weight 600). Overlaid with a 1px border (`rgba(255, 255, 255, 0.3)`). Hover activates a neon aura (`box-shadow: 0 0 24px -2px rgba(6, 182, 212, 0.45)`). Active state applies `transform: scale(0.98)`.
- **Secondary Glass Button**: Background `rgba(255, 255, 255, 0.04)` with a 1px border (`rgba(255, 255, 255, 0.12)`) and light slate text (`#f1f5f9`). Hover shifts background to `rgba(255, 255, 255, 0.08)` and border to `rgba(6, 182, 212, 0.4)`.
- **Ghost Action**: Transparent fill, `#94a3b8` text, transitioning to `#f8fafc` with subtle `rgba(255, 255, 255, 0.05)` backing on hover.

### Frosted Cards & Bento Containers
Constructed with `rgba(13, 17, 28, 0.72)` background, `backdrop-filter: blur(20px)`, and a 1px hairline border of `rgba(255, 255, 255, 0.08)`. An inner top highlight `inset 0 1px 0 rgba(255, 255, 255, 0.09)` provides tactile depth. On hover, the border shifts to a cyan-blue gradient sheen, accompanied by an ambient glow (`box-shadow: 0 12px 36px -8px rgba(6, 182, 212, 0.15)`).

### CLI Terminal & Code Windows
- **Chrome Header**: Deep surface (`#0d111c`) housing three 10px circular control dots (close `#ef4444`, minimize `#f59e0b`, expand `#10b981` at 60% opacity) and a centered monospace window title (`dbctx v0.4.1`).
- **Terminal Canvas**: Deep obsidian interior (`#05070f`) with Geist Mono 13px code output, accented with glowing cyan command prompts (`$ dbctx build`) and emerald status output.
- **Copy Trigger**: Floating glass icon button on the top right with smooth transition feedback to an emerald checkmark.

### Protocol Status Badges & Chips
- **Agent Interoperability Pills (MCP Ready)**: 28px height pill (`rounded-full`) in `rgba(255, 255, 255, 0.04)` with a 1px border (`rgba(255, 255, 255, 0.1)`). Left slot features an agent icon alongside a 6px pulsing emerald dot (`#10b981`), paired with 12px Geist label.
- **Engine Score Badges**: Ultra-compact 10px monospace caps (`rounded-sm`) displaying lexical/semantic search contributions (`FTS: 1.0`, `SEMANTIC: 0.89`, `FUZZY: 0.75`).

### Schema Relationship Graph Nodes
- **Table Card**: Compact `#0d111c` panel with a bold monospace title, row count estimates (`~180k rows`), and column lists displaying primary key tags (`#ce9178` on `#3d1f00`) and foreign-key indicators (`#10b981` on `#0d3d2a`).
- **Connection Vectors**: SVG bezier lines with animated cyan pulse dashes (`rgba(6, 182, 212, 0.4)`) linking foreign-key columns across visualizer nodes.

### Inputs & Inspection Filters
Dark input fields (`#09090b`) with a 1px hairline border (`rgba(255, 255, 255, 0.12)`). Monospace placeholder text (`#64748b`). Focus states activate a 1px cyan outline (`#06b6d4`) and an ambient neon glow (`0 0 0 3px rgba(6, 182, 212, 0.15)`).
