The 60-Second Setup

Add schema-lens to your coding agent configuration and give it immediate relational awareness.

folder_open ~/Library/Application Support/Claude/claude_desktop_config.json 
{
  "mcpServers": {
    "dbctx": {
      "command": "npx",
      "args": ["dbctx", "mcp-serve"]
    }
  }
}
